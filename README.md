# 浅泽 KARDS DIY

为卡牌设计提供网页版、Android APK 和 Windows EXE。项目延续原有制卡编辑布局，并加入高级异画模块。

## 使用入口

- 网站：发布成功后补充正式地址。
- Android 和 Windows：安装包在 [GitHub Releases](https://github.com/QZgx/qianze-kards-diy/releases) 发布。
- 项目仓库：[QZgx/qianze-kards-diy](https://github.com/QZgx/qianze-kards-diy)。

## 制卡功能

保留普通制卡、闪卡与预设模板。高级异画目前提供：

| 模块 | 作者标注 | 使用方式 |
| --- | --- | --- |
| 铸钢——来自BigC | BigC | 软件和网站都需要密钥，联网验证后使用 |
| 碧蓝航线——来自浅泽 | 浅泽 | 直接使用，仅提供指令卡模板 |

碧蓝航线模板提供金、紫、蓝、银白四种卡框，分别对应精英、特殊、限定、普通。支持费用、名称、描述、图片上传和 PNG 导出；阵营徽记以 30% 不透明度显示在描述框背景。

铸钢的密钥不随客户端发布。请通过作者提供的渠道取得密钥，不要将密钥提交到仓库、Issue 或截图中。
